# Parker Desktop

Installers for Parker Desktop. Both links always resolve to the newest
release, so they never go stale.

[![Download for macOS](https://img.shields.io/badge/Download-macOS-1a1a18?style=for-the-badge&logo=apple&logoColor=white)](https://github.com/real-simple-labs/parker-desktop-releases/releases/latest/download/Parker-Desktop.dmg)
[![Download for Windows](https://img.shields.io/badge/Download-Windows-0078d4?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/real-simple-labs/parker-desktop-releases/releases/latest/download/Parker-Desktop-Setup.exe)

- **macOS** - `Parker-Desktop.dmg`, universal (Apple silicon and Intel).
- **Windows** - `Parker-Desktop-Setup.exe`, 64-bit, Windows 10 and 11.

Parker Desktop updates itself after the first install, so these links are only
for getting started.

## Windows shows a warning on the first run

The Windows installer is not code-signed yet, so Windows greets it with
"Windows protected your PC". Choose **More info**, then **Run anyway**. It
installs for your user account only, so there is no administrator prompt, and
later updates arrive quietly with no warning.
